本篇是**研究论文**，不是综述。除通用要求外，额外注意：

1. **正文结构照原样译**：Abstract / Introduction / Experimental（或 Methods）/ Results /
   Discussion / Conclusion / Acknowledgments 的标题与顺序一节不改。
   原文的补充材料（Supporting Information）通常不在 `paper.md` 里——**不要凭空补**；
   正文出现「见补充材料 Fig. S3」这类指引就照译，保持它的指向。
2. **Experimental / Methods 译准**：仪器与方法名、温度、时间、倍率、电解液配比、
   电极负载量等数值与单位照抄原值（原文没给就写「原文未给出」）。
   英文缩写首次出现给全称，如「选区电子衍射（selected area electron diffraction, SAED）」。
3. **批注盯着「作者的证据能不能撑住作者的话」**，优先问这几件事：
   - **n 与误差**：这条结论基于几个样品 / 几颗颗粒 / 几次循环？误差棒是标准差还是标准误？
     有没有统计检验？**n 与误差若只出现在补充材料里，也要写明「主文未给」**。
   - **对照**：比较基准是不是同批次合成、同一电解液、同一测试条件？变量是不是只有一个？
   - **表征与结论的对应**：这句话由哪张图支撑？图上是哪个量、在什么条件下测的？
     有没有「图上只是相关、正文写成因果」的地方？
   - **外推边界**：只测了单一化学计量（如只有 NMC111）、单一倍率或单一电压窗口的结论，
     被写成普适时必须点出来。
   - **与库内文献**：印证、补充，还是**冲突**——冲突要说清是哪一篇、在哪个量上不一致。
4. **读前批注**要指认：全文最吃重的那一个论点（通常压在一张图上）、支撑它的样本量与条件、
   以及**它没有展示的东西**（只存在于补充材料、或干脆没做）。
